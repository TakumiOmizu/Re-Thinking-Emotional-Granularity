# Re-Thinking-Emotional-Granularity
This repository provides supplementary materials for the paper entitled “Rethinking Emotional Granularity: A Dynamic Network Approach Using GVAR and Stochastic Differential Equations.” The repository contains the following resources:
Online Resource 1: Supplementary material for the simulations and empirical analyses.
Online Resource 2: R scripts used for all analyses and simulations (analysis.qmd).
Online Resource 3: Element-level bias, MAE, and RMSE for PCC estimation across the 16 additional simulation conditions.
